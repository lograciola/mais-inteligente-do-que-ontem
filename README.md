# MIQO — mais inteligente do que ontem

Aplicativo de curiosidade e aprendizado pessoal. O MIQO ajuda a descobrir temas, explorar conceitos e ampliar o repertório, um assunto por vez.

## Arquivos

- `dist/index.html`: aplicativo completo
- `dist/`: ícones e manifesto da versão instalável
- `.openai/hosting.json`: configuração do MIQO no Sites

Para editar no Codex, abra este repositório e escolha a branch `main`.
